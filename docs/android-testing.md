# Проверки Android-приложения на устройстве

Установка: `adb install -r android/out/vkturn-<версия>-arm64-v8a.apk` (или universal). Журнал
демона — на экране приложения («Копировать журнал») и в `adb logcat` не дублируется.

1. **Ключи.** «Новый ключ» → поле приватного ключа заполнено, ниже публичный; совпадает с
   `echo <приватный> | vk-turn-proxyd pubkey` на роутере.
2. **Запуск.** «Подключить» → системный диалог VPN → «Подключение к релеям VK…» (VPN ещё не
   поднят, значка ключа нет) → «Рукопожатие WireGuard…» (значок появился) → «Туннель работает».
   В журнале: `proxy: first connection up`, `wireguard: handshake in`.
3. **Трафик.** Браузер в туннеле: внешний IP — сервера. Скорость — сравнить с роутером при тех же
   `conns`.
4. **Раздельное туннелирование.**
   - «Только выбранные» = {браузер A}: IP в A — сервера, в браузере B — оператора;
   - «Все, кроме выбранных» = {A}: наоборот;
   - сам VK TURN в туннель не попадает ни в одном режиме (иначе петля — сессии умрут за минуты).
5. **Локальные сети.** С «мимо туннеля» открывается веб-морда роутера 192.168.x.1 через Wi-Fi;
   без — не открывается (если сервер не маршрутизирует такую сеть).
6. **Смена сети.** Wi-Fi → LTE и обратно: в журнале `network: …`, туннель восстанавливается без
   перезапуска (как handover на роутере); `conns_active` возвращается к норме.
7. **Остановка.** «Отключить» или из уведомления: в журнале `app: stdin closed — stopping`,
   `stopped`; значок VPN пропал. Повторный старт сразу после — без ожидания 10 минут
   (свежий кэш кредов отбрасывается, `dropFreshCache`).
8. **Отзыв.** Включить другой VPN — VK TURN останавливается с «VPN отключён системой…».
9. **Always-on.** Настройки → VPN → VK TURN → «Постоянная VPN»: после перезагрузки поднимается сам.
10. **Нет сети при старте.** Режим полёта → «Подключить»: «Подключение к релеям…» без падения;
    сеть вернулась — туннель поднялся.
