# Подключить устройство

Профиль выдаёт панель на сервере (репозиторий vk-turn-proxy, скил `issue-connection`): одно
подключение — одно устройство, свои ключи и адрес. Один профиль на два устройства не ставить —
они будут выбивать друг друга с сервера (одинаковый WireGuard-ключ).

## Android

1. Установить приложение (скил `android-release`).
2. «Импорт подключения» → один из вариантов:
   - «Сканировать QR-код» — QR на экране панели (камера запросит разрешение один раз);
   - «Вставить ссылку из буфера» — ссылка `vkturn://import?c=…` скопирована на телефоне;
   - «Открыть файл .vkturn» — файл из панели, пересланный себе.
   Ссылка, открытая из мессенджера, сразу открывает этот диалог.
3. В диалоге проверить сервер и адрес → «Подключить». Маршруты и выбор приложений для раздельного
   туннелирования импорт не трогает.

## OpenWrt

Пакеты должны стоять (скил `router-install`). Дальше:

- LuCI → Network → Interfaces → VK TURN → поле **Import** → ссылка → Import → Save & Apply;
- или скрипт из панели — в SSH-консоль роутера.

## Формат профиля

`vkturn://import?c=<base64url(JSON)>`, JSON — как файл `.vkturn`:
`{"v":1,"name","peer","server_key","private_key","psk","address","dns","mtu","conns","transport","vk_links":[…]}`.
Читатели: `android/.../ProfileImport.kt`, `openwrt/luci-proto-vkturn/.../protocol/vkturn.js`
(`parseProfile`). Источник — `panel/profile.go` в vk-turn-proxy. Правила изменения формата — в
CLAUDE.md.

## Не работает

| Симптом | Где смотреть | Причина и что делать |
|---|---|---|
| «Подключение к релеям VK…» висит | журнал (Android «Журнал», роутер `logread -e vkturn`) | капча или мёртвая ссылка на звонок: свежая ссылка в настройках панели → повторный импорт |
| `captcha_needed` | статус | кнопка «Открыть капчу» (Android) / ссылка на странице Status → VK TURN |
| сессии есть, «Рукопожатие WireGuard…» не проходит | на сервере `wg show wg0` | peer отключён в панели; не тот сервер или порт в профиле; закрыт 56004/udp; сервер без `-srtp` |
| рукопожатие есть, сайтов нет | — | NAT/forwarding на VPS; DNS в профиле; на роутере — трафик не направлен в `vkturn` (NetShift/зона firewall) |
| после смены сети долго нет связи | статус `conns_active` | нормальное восстановление занимает до ~2,5 мин |
